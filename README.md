💡 Problem

Students planning higher education face a fragmented journey:

- Confusion in choosing the right course and country
- High cost of biased consultancy services
- Fear of loan rejection
- No connection between career decisions and financial planning

---

✅ Solution

PathwayAI is an AI-powered platform that combines career guidance with financial intelligence.

Core Modules

- 🎯 Career Navigator — University recommendations based on profile
- 📈 ROI Predictor — Salary & payback estimation
- 🏦 Loan Eligibility Engine — ML-based approval prediction
- 📅 Smart Timeline — Step-by-step roadmap
- 💬 AI Mentor — 24/7 guidance

---

🧠 How It Works

1. User enters academic and financial details
2. AI processes inputs across multiple modules
3. Platform generates personalized recommendations and insights

---

🛠️ Tech Stack

- Frontend: React + TypeScript + Vite
- Styling: Tailwind CSS
- Backend: FastAPI (Python)
- Machine Learning: RandomForest (scikit-learn)
- AI Chatbot: Gemini 1.5 Flash
- Deployment: Vercel + Render

---

⚙️ Run Locally

Backend

cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

Frontend

cd frontend
npm install
npm run dev

---

🔐 Environment Variables

Create a ".env" file:

GEMINI_API_KEY=your_api_key
FRONTEND_URL=http://localhost:5173
